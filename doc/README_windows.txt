ConnectCoin Core
================

ConnectCoin is an experimental UTXO cryptocurrency derived from Bitcoin Core.
This development build is not production-ready and may change its network and
wallet formats without compatibility guarantees.

Setup
-----
Unpack the files into a directory and run connectcoin-qt.exe for the graphical
client, or daemon/connectcoind.exe for the headless node.

By default, application data is stored under:
  %LOCALAPPDATA%\ConnectCoin

The regtest network is recommended for local mining and wallet tests.
