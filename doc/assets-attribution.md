The ConnectCoin application icon was generated specifically for this project
with OpenAI image generation on 2026-08-25. The generated design uses
interlocking cyan and teal links forming a letter C on a navy background and
does not reuse the upstream Bitcoin logo.

The monochrome Automatic claims navigation icon (a globe with meridians) is
original ConnectCoin artwork, distributed under the repository's MIT license.
Its editable vector source is `src/qt/res/src/p2c_claim.svg`.

The P2C navigation icon combines that globe with a send arrow adapted from
Stephen Hutchings' MIT-licensed Typicons, matching the inherited Send icon.
Its editable vector source is `src/qt/res/src/p2c.svg`. Both navigation icons
have transparent 128-by-128 PNG exports in `src/qt/res/icons/`, used like the
other navigation icons without an SVG plugin.
