The ConnectCoin application icon was generated specifically for this project
with OpenAI image generation on 2026-08-25. The generated design uses
interlocking cyan and teal links forming a letter C on a navy background and
does not reuse the upstream Bitcoin logo.

The monochrome P2C navigation icon (a globe with meridians) is original ConnectCoin
artwork, distributed under the repository's MIT license. Its editable vector
source is `src/qt/res/src/p2c.svg`; `src/qt/res/icons/p2c.png` is its transparent
128-by-128 export, used like the other navigation icons without an SVG plugin.
